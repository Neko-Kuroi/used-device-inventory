# used-device-inventory

中古のスマートフォンとパソコンを、機種単位ではなく **1台ごと (個体)** に
管理するための在庫台帳です。Tshirt3 とは別系統の新規プログラムで、
作り方 (Flask + 標準ライブラリ sqlite3、テストで固める) だけを参考にしています。

設計と決定事項の正本は [PLAN.md](PLAN.md) です。

## 起動方法 (試用)

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

ブラウザで http://127.0.0.1:5000/ を開くと、最初の管理者を作成する
初期設定画面が出ます (ユーザーがいる場合はログイン画面になります)。

- データベース: `instance/devices.db` (SQLite、自動作成)
- セッション用の鍵: `instance/secret_key` (初回に自動生成、権限 600)

## 運用メモ (Tailscale で複数端末から使う場合)

- ホストの PC で本プログラムを常駐させ、他の端末からは Tailscale 経由で
  アクセスします。一般のインターネットには公開しません。
- 開発用サーバー (`run.py`) は試用向けです。日常運用では Waitress 等の
  本番用サーバーで、Tailscale のアドレスにだけ bind してください。
- データベースのバックアップは、ホスト以外の場所にも定期的に取ってください。写真を使っている場合は `instance/photos/` も一緒に取ってください。

## 決まっている扱い

- IMEI: 判別できたものは記録します。全文が見えるのは管理者だけです
  (一覧では末尾4桁のみ、詳細でも一般ユーザーは末尾4桁のみ)。
  判別できない場合は空欄で、その個体のネットワーク利用制限は
  「確認できず」と記録されます。
- 状態ランク: S / A / B / C / ジャンク の5段階です。
